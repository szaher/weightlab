# Delivery notes — 2026-11-05

## What exists

- **18 detailed engineering/product documents** in `docs/` (the only source of truth).
- **Combined Markdown volume** `WeightLab_Complete_Blueprint.md`, generated by `scripts/build_documentation.py`; `--pdf` renders a PDF (needs pandoc and weasyprint). Do not edit generated files.
- **OpenAPI 3.1 draft** (`contracts/openapi.yaml`, 0.2.0-draft) plus JSON Schema for experiment manifests and a validated sample manifest.
- **Byte-reproducible synthetic fixture generator** and an **independent fixture checker** (own SafeTensors parser, no `safetensors` dependency for reference values).
- **Fixtures** in `examples/fixtures/`: base/fine-tune pair, BF16/F16 dtypes, sharded index, three LoRA adapters (incl. rsLoRA and an unsupported DoRA), compatibility sets, 11 malformed binaries and 4 malformed index directories, `expected_results.json`.
- **Coding-agent handoff** in `agent/IMPLEMENTATION_AGENT_HANDOFF.md`.

## What does not exist

No WeightLab app, UI, production reader or trained model has been implemented. Performance targets, release gates, third-party compatibility and research questions are requirements, not measured claims. The fixture `tiny_ft` contains artificial changes, not training or any capability. Optional inference requires more RAM and dependencies than weight inspection; no universal transfer of reasoning is promised.

## Revision 1.1 (review fixes)

- BF16/F16 mandatory from R0; WeightLab decodes BF16 itself (safetensors 0.8.0's NumPy backend cannot). Positioned-read reader instead of mmap (SIGBUS, Windows locks). ADR-011.
- Tiles: direct reads for L0-L3, exact one-pass pyramid for L>=4, row-sampled preview only above `pyramid_exact_max_mib`; separate tile (65,536) and ROI-table (4,096) budgets. ADR-012.
- New R0.5 `weightlab diff` change report CLI (FR-023) and practitioner validation before the UI. ADR-013.
- Operational Class V lineage verification (hashes, offline HF cache blob hashes, user attestation). ADR-014.
- R3 evaluation on the viewer's own weights via transformers + PEFT; layer interventions as small derived adapters. ADR-015.
- Launch token delivered via URL fragment. ADR-016.
- LoRA: `fan_in_fan_out`, `rank_pattern`/`alpha_pattern`, `layers_to_transform`, embedding LoRA and DoRA rejection; tied embeddings reported as tied, not missing.
- Contradictions resolved: memory targets, tile JSON vs binary (binary format with status channel now specified in OpenAPI), job budget clamping, fixture script name, duplicate API row, offset gap rule.
- Fixtures: renamed `tiny_math` to `tiny_ft`; added rank-0, 1x1, BF16/F16, `down_proj`, rank-1/rsLoRA/DoRA adapters, `compat/`, malformed binaries; full 8x8 expectations for AC-001; all pseudo-random values via SplitMix64.
- Found while regenerating fixtures: `safetensors.numpy.save_file` (0.8.0) silently transposes non-C-contiguous arrays and does not keep multi-key metadata order stable. The generator works around both (doc 03 section 11).
- Reference 12 (Klabunde & Lemmerich) marked unverified.
- The previously shipped PDF was no longer in the working tree at revision time; regenerate with `--pdf` if needed.
